# results/

Produced when the scripts are run:

* `figures/`: figures (PNG), named as in the dissertation
* `tables/`: tab-separated tables (for example the Chapter 4 TOMTOM pairwise table)
* `reported_values.tsv`: every value quoted in the text, written by the analysis
  scripts, each with a short identifier (columns `section`, `name`, `value`)
* `checkpoints/`: intermediate state of long permutation runs
